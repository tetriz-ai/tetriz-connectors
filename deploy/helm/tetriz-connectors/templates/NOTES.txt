tetriz-connectors {{ .Chart.AppVersion }} is running as {{ include "tetriz.fullname" . }} in {{ .Release.Namespace }}.

Check health (prints "ok" once Postgres and Redis answer):

  kubectl -n {{ .Release.Namespace }} port-forward svc/{{ include "tetriz.fullname" . }} {{ .Values.service.port }}:{{ .Values.service.port }} &
  curl localhost:{{ .Values.service.port }}/_health

Store a connector config and run one sync from a runner pod:

  kubectl -n {{ .Release.Namespace }} exec deploy/{{ include "tetriz.fullname" . }} -- \
    tetriz-connectors config put --org <ORG_UUID> --connector github \
    --settings '{"include_private":true}' --credentials '{"personal_access_token":"<TOKEN>"}'
  kubectl -n {{ .Release.Namespace }} exec deploy/{{ include "tetriz.fullname" . }} -- \
    tetriz-connectors sync --org <ORG_UUID> --connector github --op fetch_repos
